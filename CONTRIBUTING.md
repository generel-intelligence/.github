# Contributing

Generel Intelligence is pre-alpha. Public contributions are currently limited
to governance, documentation, and catalog corrections. Please do not submit
implementation work assigned to a later milestone.

## Pull requests

1. Keep each change narrowly scoped.
2. Explain the current problem and the proposed correction.
3. Update documentation when a durable contract changes.
4. Ensure the repository's required checks pass.

Do not include secrets, private benchmark material, hidden evaluators, or
third-party content without verified redistribution rights.

## Developer Certificate of Origin

Every commit to a public repository must include a `Signed-off-by` trailer
certifying the [Developer Certificate of Origin 1.1](https://developercertificate.org/).

Use:

```text
git commit -s
```

Contributions are provided under the license of the repository receiving them.
No contributor license agreement is required.

## Security

Do not report vulnerabilities in public issues. Follow the receiving
repository's `SECURITY.md`.
