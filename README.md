# Generel Intelligence organization governance

This repository owns the shared governance, contribution templates, and
reusable policy checks for the
[Generel Intelligence](https://github.com/generel-intelligence) organization.

The organization is pre-alpha. Public contributions are currently limited to
governance, documentation, and catalog corrections.

## Contents

- `.github/workflows/` contains the reusable governance and secret-scanning
  checks.
- `.github/ISSUE_TEMPLATE/` and `.github/PULL_REQUEST_TEMPLATE.md` provide
  organization defaults.
- `profile/README.md` provides the public organization profile.
- `CONTRIBUTING.md` and `SECURITY.md` are the canonical organization policies.

Repository-specific behavior remains documented in each repository.
